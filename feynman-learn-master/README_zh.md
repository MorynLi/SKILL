# feynman-learn

feynman-learn 是一个费曼解释 skill。它帮助助手把复杂知识讲成外行能懂的故事，再把专业要点挂回这个故事。

它适合这些场景：

- 理解一个概念、机制、区别或流程
- 把技术话题讲给外行听
- 学习一条链路、管线或训练流程
- 检查自己的解释是否清楚
- 在用户明确要求时，建立知识地图或学习计划

## 核心想法

这个 skill 的目标是让用户听懂，而不是让助手显得完整。

好的解释应该：

- 先给一个生活里熟悉的画面
- 把这个画面当成理解骨架
- 把每个专业术语对应到故事里的角色、动作或结果
- 讲流程时说明之前是什么、之后变成什么
- 最后留下一个用户能复述的说法

## 使用方式

普通概念问题，用一个熟悉故事和一个小例子讲懂。

流程问题，顺着故事主线讲每一步发生了什么变化。

知识地图或学习计划问题，只有在用户明确要求时才给结构和顺序。

这个 skill 避免固定模板、强制分节，以及把小问题扩成课程。

## 示例

解释大模型训练时，可以使用“培养一个新员工”这个故事：

- 数据清洗：整理干净教材
- 预训练：大量读资料、做填空练习
- 指令微调：学习按任务办事
- 对齐：学习什么回答更合适、更安全
- 评测：考试
- 部署：上岗
- 用户反馈：复盘真实工作，下一轮继续改进

每个专业要点都能回到同一个故事里，解释才稳。
