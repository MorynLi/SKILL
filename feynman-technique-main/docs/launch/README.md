# Launch drafts

Four texts, one per platform. Not the same text four times — each community reads
differently, and a post that was obviously written for somewhere else reads as broadcast.

| File | Where | Reloads? |
|---|---|---|
| [reddit.md](reddit.md) | r/ClaudeAI, then others | yes |
| [devto.md](devto.md) | dev.to / Hashnode | yes |
| [x-thread.md](x-thread.md) | X | yes |
| [show-hn.md](show-hn.md) | Hacker News | **no** |

## Order

**Show HN last.** It is the only one that cannot be repeated — a submission that lands flat
is spent, and you do not get to try again with better wording. Post Reddit and dev.to first,
watch which sentences people quote back at you, and fold that into the HN comment before
spending it.

A reasonable sequence:

1. **dev.to** — it is the only piece that is worth reading on its own, so it becomes the
   thing the others link to.
2. **Reddit** — r/ClaudeAI first. Check the sub's self-promotion rule; most require account
   history, so if yours is fresh there, participate for a few days before posting.
3. **X** — the hero image does the work. Post 1 has to stand alone.
4. **Show HN** — once you know which framing landed.

## The rule that keeps this from being spam

Every one of these is you saying "I built this", on your own account, in a place where that
is welcome. That is fine and normal.

What is not fine is finding threads where someone has a problem and dropping a link. The
test, for any comment you are considering: **delete the link — does the comment still help
the person?** If yes, post it. If no, it was an advertisement and it will be treated as one.

## Things to have ready before you post any of them

- **A real answer.** Not the README's example — a fresh one, from a question someone in the
  thread asked. It converts better than every paragraph in these drafts combined.
- **The hero as PNG.** Export `assets/hero.svg` at 2x. X compresses SVG badly and sometimes
  rejects it.
- **The honest limits, unprompted.** He didn't invent the four steps. The Einstein quote
  isn't Einstein's. Some things don't simplify. Saying these before anyone asks is what
  makes the rest credible — and on HN it is the difference between a good thread and a
  thread about your credibility.

## What not to claim

The repo is new and has almost no users. Nothing here should imply otherwise: no "used by",
no invented download counts, no testimonials. The measurements are real and checkable —
those are the claims worth making, and they are enough.
